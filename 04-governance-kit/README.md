# 04 · BI Governance Kit

The standards I use to keep Power BI work consistent, reviewable and fast once more than one
developer touches it.

| File | What it gives a team |
|---|---|
| [STANDARDS.md](STANDARDS.md) | Naming conventions, modelling and DAX rules, performance sign-off checklist, `.pbip` + Git release flow, security and a PR review checklist |
| [theme/northwind-corporate.json](theme/northwind-corporate.json) | Report theme (colours, fonts, visual defaults), importable via *View › Themes › Browse for themes* |

All three projects in this repository follow these standards.
